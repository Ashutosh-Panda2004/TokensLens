# Support

## Community support

- Use [GitHub Issues](https://github.com/Ashutosh-Panda2004/TokensLens/issues) for reproducible bugs
  and concrete feature requests.
- Use the bug template and include TokenLens, Node.js, VS Code, and operating-system versions.
- Run `tokenlens --version`, `tokenlens config`, and the smallest relevant command before reporting.

Public support is best effort. Remove prompts, completions, local paths, account names, tokens,
session identifiers, and organisation data from screenshots and logs. Prefer synthetic examples.

## Security support

Do not use a public issue for vulnerabilities or suspected data exposure. Follow
[SECURITY.md](SECURITY.md).

## Enterprise support

The repository does not currently promise a commercial SLA. Organisations can use the deployment
checklist in [ENTERPRISE.md](ENTERPRISE.md) and arrange their own internal support model. Any future
paid support terms will be documented separately and will not change the MIT license of this code.
