# Support

Use the [TokenLens issue tracker](https://github.com/Ashutosh-Panda2004/TokensLens/issues) for
reproducible extension bugs and feature requests.

Do not attach prompts, completions, journals, bearer tokens, private paths, session identifiers, or
organisation data. Follow the repository [security policy](https://github.com/Ashutosh-Panda2004/TokensLens/blob/main/SECURITY.md)
for vulnerabilities or suspected data exposure.
