# Code of Conduct

TokenLens contributors and maintainers are expected to make participation safe, respectful, and
technically constructive.

## Expected behavior

- Discuss ideas and code without attacking the person presenting them.
- Give actionable feedback and state uncertainty honestly.
- Respect privacy, consent, attribution, and the confidentiality of security reports.
- Welcome people regardless of identity, background, experience, location, or employer.
- Stop behavior when someone clearly identifies it as unwelcome.

Harassment, threats, discriminatory language, sexual attention, deliberate humiliation, doxxing,
or publishing another person's private material are not acceptable in project spaces.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub profile or a private
security advisory when confidentiality is needed. Maintainers may edit or remove content, issue a
warning, restrict participation, or ban an account. Reports will be handled as confidentially as
practical, and retaliation against a reporter is prohibited.

This policy applies to repository discussions, issues, pull requests, reviews, community events,
and public interactions where someone represents TokenLens.
